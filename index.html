Como funciona
Não precisa configurar nada.
  1. O sistema já vem conectado ao banco de dados do Supabase da 2M Commerce.
  2. Qualquer alteração (produto, custo, lote) é salva no banco e aparece instantaneamente para os outros colaboradores conectados.
  3. Se a internet cair, o sistema continua funcionando com os dados salvos localmente e sincroniza de novo quando a conexão voltar.
